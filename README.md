# bubbletea-examples

Crystal ports of the [Bubble Tea examples](https://github.com/charmbracelet/bubbletea/tree/main/examples),
built with the Crystal [Bubble Tea](https://github.com/dsisnero/bubbletea.cr) and
[Bubbles](https://github.com/dsisnero/bubbles) shards.

The examples serve three purposes:

- runnable demos of the Crystal ports;
- parity fixtures, with Go harnesses and goldens under `goldens/` and `spec/`;
- the source of the component GIFs used by the Bubbles README.

## Requirements

- Crystal >= 1.19.1
- `shards install` dependencies (see `shard.yml`)

## Build and run

```bash
shards install
make build          # builds every src/*.cr into build/
./build/spinner
./build/textarea
```

`make build` produces released binaries. For a quicker debug build of one
example:

```bash
mkdir -p build
crystal build -o build/textarea src/textarea.cr
```

## Tests

```bash
make test           # crystal spec
```

The parity specs compare captured example output with goldens generated by the
Go harnesses in `goldens/`.

## Example GIFs (VHS)

The Bubbles README assets are recorded from these examples with
[VHS](https://github.com/charmbracelet/vhs). Upstream commits recorded GIFs next
to its examples; this repo also keeps the tapes so the recordings are
reproducible.

```bash
make gifs           # builds the recorded examples and runs tapes/*.tape
```

The recordings are written to `gifs/` and use these tapes:

| Example | Tape | Output |
|---------|------|--------|
| `src/spinner.cr` | `tapes/spinner.tape` | `gifs/spinner.gif` |
| `src/textinput.cr` | `tapes/textinput.tape` | `gifs/textinput.gif` |
| `src/textarea.cr` | `tapes/textarea.tape` | `gifs/textarea.gif` |
| `src/tree.cr` | `tapes/tree.tape` | `gifs/tree.gif` |
| `src/table.cr` | `tapes/table.tape` | `gifs/table.gif` |
| `src/progress_animated.cr` | `tapes/progress_animated.tape` | `gifs/progress.gif` |
| `src/viewport.cr` | `tapes/viewport.tape` | `gifs/viewport.gif` |
| `src/list_default.cr` | `tapes/list_default.tape` | `gifs/list.gif` |
| `src/file_picker.cr` | `tapes/file_picker.tape` | `gifs/filepicker.gif` |
| `src/help.cr` | `tapes/help.tape` | `gifs/help.gif` |
| `src/paginator.cr` | `tapes/paginator.tape` | `gifs/pagination.gif` |
| `src/timer.cr` | `tapes/timer.tape` | `gifs/timer.gif` |
| `src/stopwatch.cr` | `tapes/stopwatch.tape` | `gifs/stopwatch.gif` |

Requirements: Crystal, VHS, `ttyd`, and `ffmpeg`. Build artifacts (`build/`) are
ignored; the generated GIFs are committed so the Bubbles README can reference
them without running the recorder.

To update the Bubbles README assets:

```bash
make gifs
cp gifs/*.gif ../bubbles/docs/assets/
```
